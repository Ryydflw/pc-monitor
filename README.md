# PC Monitor

Мониторинг ПК в реальном времени для Windows: графики CPU, GPU, ОЗУ, потребления и FPS игр, оверлей поверх игры и сводка пиков.

## Скачать

Откройте раздел **Releases** и скачайте `PcMonitor-1.0.0.exe`. Это один файл, больше ничего ставить и скачивать не нужно.

## Возможности

- Процессор: загрузка, температура, частота (эффективная, как в Диспетчере задач), мощность.
- Видеокарта: загрузка, температура, частота, мощность, видеопамять (VRAM).
- ОЗУ: загрузка в процентах.
- Потребление системы — оценка: CPU + GPU + 70 Вт, с пиковым значением.
- FPS и время кадра текущей игры; резкие просадки (ниже среднего более чем на 30%) отмечаются красным.
- Панель «Статистика» у левого края: наведите мышь — покажет игру, FPS с оценкой (зелёный — хорошо, жёлтый — баланс, красный — просадка) и пики за сеанс.
- Оверлей поверх игры: кнопка в окне или **Ctrl+Shift+O**.

## Требования

- Windows 10 или 11, 64-бит.
- Права администратора (программа запросит их при запуске) — без них недоступны датчики и FPS.
- .NET Framework 4.7.2 или новее (уже есть в Windows 10 1803+ и Windows 11).

## Как это работает

При первом запуске exe распаковывает программу в `%LOCALAPPDATA%\PcMonitor\` и запускает её оттуда.
Датчики читаются через LibreHardwareMonitor, FPS — через Intel PresentMon. Обе утилиты уже внутри exe.

## Ограничения

- Встроенная графика Intel отдаёт только частоту; загрузка, температура, мощность и VRAM доступны на дискретных видеокартах AMD и NVIDIA.
- Потребление системы — оценка, а не измерение.
- В эксклюзивном полноэкранном режиме игра может перекрыть оверлей — используйте «оконный без рамки».
